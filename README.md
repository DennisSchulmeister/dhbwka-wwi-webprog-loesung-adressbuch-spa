# Webprogrammierung / Lösung / Adressbuch (SPA)

Dies ist die **Musterlösung** zur Aufgabe „Adressbuch (SPA)" aus der Vorlesung **Webprogrammierung** (Wirtschaftsinformatik, DHBW Karlsruhe), Kategorie *JavaScript*.

Ein Adressbuch mit Anzeigen, Anlegen, Bearbeiten und Löschen von Kontakten wird als objektorientierte Single Page App mit eigenem SPA-Router umgesetzt.

Dieses Repository ist Teil der Quellcodes [dhbwka-wwi-webprog-quellcodes](https://github.com/DennisSchulmeister/dhbwka-wwi-webprog-quellcodes) zur Vorlesung Webprogrammierung.
